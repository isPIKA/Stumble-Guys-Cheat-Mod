## Installation

1. Install [MelonLoader](https://github.com/LavaGang/MelonLoader) **v0.7.3** for `Stumble Guys.exe` using **x64**.
2. Launch the game once, then close it.
3. Download `sgPIKACHUMod.dll` from **Releases**.
4. Copy the DLL to:

```text
C:\Program Files (x86)\Steam\steamapps\common\Stumble Guys\Mods
```

5. Launch the game and press **F2**.
6. Enter your License Key and press **ACTIVATE**.
